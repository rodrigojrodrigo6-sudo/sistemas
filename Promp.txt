Quiero crear una aplicación web fullstack moderna usando Next.js + Supabase + TailwindCSS.

La aplicación será un gestor de sitios web pendientes por visitar.

OBJETIVO:
Permitir que un usuario guarde sitios web, los marque como visitados y administre su lista de seguimiento.

STACK TECNOLÓGICO:
- Next.js App Router
- TypeScript
- TailwindCSS
- Supabase
- PostgreSQL
- Deploy preparado para Vercel

REQUISITOS GENERALES:
- Código limpio y modular
- Diseño responsive
- UI moderna y minimalista
- Componentes reutilizables
- Variables de entorno para credenciales
- Preparado para producción
- Buen manejo de estados
- Buen manejo de errores
- Loading states
- Confirmaciones visuales
- Código comentado

AUTENTICACIÓN:

ESTRUCTURA DE LA BASE DE DATOS:

Tabla: sitios_web

Campos:
- id (uuid, primary key)
- user_id (uuid)
- nombre (text)
- url (text)
- descripcion (text, opcional)
- categoria (text, opcional)
- visitado (boolean)
- fecha_visita (timestamp, opcional)
- created_at (timestamp)

Crear políticas RLS para que cada usuario vea solo sus datos.
